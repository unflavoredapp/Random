# tetherless.dev OTA pack

Generated by `../scripts/gen-pack.sh`. Deploy the resulting files to the apex VPS:

- `pack.json` → `https://tetherless.dev/pack.json`
- `server.crt`, `server.pem`, `ca.crt`, `commonName.txt` alongside it (optional; the app only needs `pack.json`)

DNS: `*.tetherless.dev` A → `127.0.0.1`. Keep the apex on the VPS so the pack stays reachable.

Do not commit the generated PEMs — they are gitignored. Publish via `.github/workflows/publish-ota-pack.yml` (writes the `certs` branch) or copy them to the VPS by hand.
