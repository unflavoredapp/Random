Types are prefixed with IPadn to coexist with TetherLess AppleServices.

Included:
- Store search (IPadnStoreClient) — keyword / App ID / multi-region / delisted stubs
- Version history feeds (IPadnVersionHistory) — Timbrd / Bilin / iosdump
  (same VersionSource defaults as upstream Settings)
- Search chrome (IPadnSearchChrome) — PageHeader, capsule SearchInput, filter
  chips, AppRow + Get capsule, recent-search chips (from SearchView /
  DesignSystem / SharedViews patterns)
- Tab homes (IPadnTabHomes) — English Downloads / Purchased / Account roots
  modeled on DownloadsView, PurchasedView, AccountsView
- Store login (IPadnAppleAuthentication, IPadnHTTPClient, IPadnStoreLogin) —
  bag.xml authenticate, Configurator redirects, AMD proof loop
- WASM SAPRuntime store-proof (IPadnWASMSPSigner, IPadnLoopbackServer,
  IPadnStoreProofStore) — bundled under Resources/SAPRuntime for sapSign +
  sapStoreProofHeaders / sapStoreProvision (ADI AMD-Action SP/RP).
  Named IPadnWASMSPSigner so it does not clash with StoreSAP/SAPSigner.
  On WASM failure, login falls back once to native StoreSAP + Anisette AMD.
